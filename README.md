Open the official MetaMask Chrome Extension page.
Click Install MetaMask for Chrome → Add to Chrome → Add Extension.
After installation, pin the extension from the Chrome extensions icon.
Setup MetaMask Accounts
Create or import your wallet.
In MetaMask:
Account1 → use as Landlord
Account2 → use as Tenant

You can create Account2 from:

Profile icon → Create Account

**Workflow for Your Rental System**

**1. Connect MetaMask as Landlord**
Open your DApp in Chrome.
In MetaMask select Account1 (Landlord).
Click Connect Wallet in the app.
Approve the connection.

Check:

Connected address should match Account1.

**2. Create New Agreement**

Inside the DApp:

Click Create Agreement
Enter:
Tenant wallet address
Rent amount
Security deposit


**3. Configure It**
Review all agreement details.
Confirm transaction in MetaMask.
Wait for blockchain confirmation.

After confirmation:

Agreement should appear as Active/Pending.

**4. Switch to Tenant**

In MetaMask:

Click account icon.
Select Account2 (Tenant).

**5. Connect MetaMask as Tenant**
Refresh it if needed.
Click Connect Wallet again.
Approve MetaMask connection.

Check:

Connected wallet should now be Account2.

**6. Pay Rent**
Open the agreement.
Click Pay Rent.
MetaMask popup will appear.
Confirm payment transaction.

Wait for confirmation:

Payment status should update in the DApp.

**7. Switch Back to Landlord and Terminate**
Switch MetaMask back to Account1.
Reconnect if necessary.
Open the agreement.
Click Terminate Agreement.
Confirm the MetaMask transaction.

After confirmation:

Agreement status should become Terminated.
